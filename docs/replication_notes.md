# Replication Notes

- The paper-style branch is implemented to mirror the original framing as closely as possible with available public data and the author-provided HCS list.
- The stricter branch is intentionally separate so that replication and critique are not conflated.
- If the author file row count differs from the paper's stated value, the pipeline preserves that discrepancy and reports it explicitly.
- The expected note from the author is retained: the paper states 1792 HCS/SBC events, while the actual list contains 1793 because of IDL indexing.
